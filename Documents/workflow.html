1. User Authentication & Guard Rules

Verify role permissions, secure session storage, and router guards.

● Active Verification
1

Automatic Route Blocking

Open browser and navigate to http://localhost:5173/. Confirm that without a valid JWT, you are instantly redirected to the /login path.

2

Form Input Validations

Click the Login submit button with empty textboxes. Confirm that native validation alerts instruct you to input missing values.

3

Backend Credentials Denial

Input a fake credentials combo and submit. Verify that a beautiful red Toast slides in with a customized API error message.

4

Successful Session Creation

Login with valid user credentials. Observe the login button transforming into "Logging in..." loading state, and verify successful placement of crm_token in the LocalStorage.

Module Tech Stack
  • AuthContext.jsx
  • AuthController.cs
  • localStorage.setItem
  • JWT Token

2. Leads Pipeline Kanban & Grid

Verify smooth drag-and-drop mechanics, empty column target indicators, and persistence.

● Active Verification
1

Board Initialization

Select Pipeline in your left menu. Verify the 7 columns: New, Contacted, Qualified, Proposal Sent, Negotiation, Won, and Lost have counts and values.

2

Empty Container Drop Targets

Drag any lead card into a column with 0 entries. Confirm the column glows with a dashed-line indicator and accurately accepts the drop.

3

DND Visual Smoothness

Drag a card across columns. Observe the drag-overlay producing a clean shadow scale transition as you navigate.

4

API Persistence Verification

Drop a card in a new column. Wait for the success Toast, and reload the browser page. Confirm that the card stays positioned exactly where you left it.

Module Tech Stack
  • PipelineKanban.jsx
  • @dnd-kit/core
  • useDroppable
  • LeadsController.cs (PUT)

7. Role-Based Access Control (RBAC) Matrix

Verify permission scopes, creation rights, and visibility levels across all CRM modules.

● Active Verification

NexusCRM implements strict Role-Based Access Control (RBAC) using JWT claims. The tables below outline who is allowed to perform operations on each module:

Module & Action ■ Administrator ■ Sales Manager ■ Sales Rep
Leads Management
Sourcing opportunities 		Full Access
Can create, view all, update all, reassign, and delete leads. 		Full Access
Can create, view all, assign to reps, and delete dead leads. 		Limited
Can create new leads, view and drag/update assigned leads only. Cannot delete.
Customer Hub
Client relationship data 		Full Access
Can create, view all, edit all fields, and delete records. 		Full Access
Can create, view all, and edit profiles. Deletion blocked for safety. 		Limited
View assigned clients only. Can update basic contact details. Deletion blocked.
Tasks & Scheduling
Reminders & To-Dos 		Full Access
